# 🌴 RR Resort — Luxury Resort Website

A modern, responsive luxury resort website designed for **RR Resort**, a fictional coastal resort in Mahabalipuram, Tamil Nadu.

The website provides an elegant resort experience with information about rooms, amenities, dining, activities, gallery, guest testimonials, booking requests, FAQs, and contact details.

## ✨ Features

* 🏝️ Full-screen luxury resort hero section
* 🧭 Sticky responsive navigation bar
* 📱 Mobile-friendly responsive design
* 🛏️ Rooms & suites section with pricing and facilities
* 🏊 Resort amenities section
* 🖼️ Interactive image gallery with lightbox
* 🍽️ Restaurant and dining menu
* 🌊 Resort activities section
* ⭐ Guest testimonials slider
* 📅 Booking request form
* ❓ Interactive FAQ accordion
* 📍 Google Maps location integration
* 📞 Contact section
* 📧 Newsletter subscription UI
* ⬆️ Smooth back-to-top button
* 🌿 Animated floating leaves
* 🌊 Animated wave dividers
* ✨ Scroll reveal animations
* 🔢 Animated guest/review counters
* ♿ Reduced-motion support

The navigation provides direct access to Home, About, Rooms, Amenities, Gallery, Dining, Activities, and Contact sections.

## 🎨 Design

The website follows a premium coastal-resort visual style using:

* Gold accents
* Dark green tones
* White and light-gray backgrounds
* Elegant serif typography
* Clean sans-serif body text
* Large resort imagery
* Smooth hover and scroll animations
* Minimal luxury-inspired layouts

The design uses **Cormorant Garamond** and **Jost** fonts with a gold, green, black, white, and gray color palette.

## 🏨 Website Sections

### Home

The hero section introduces RR Resort with a coastal background, resort tagline, and booking/view-room call-to-action buttons.

### About

The About section presents the resort story, mission, vision, guest statistics, and reasons to choose RR Resort.

### Rooms & Suites

The website includes four accommodation options:

* Deluxe Room — ₹8,500/night
* Executive Suite — ₹13,200/night
* Family Villa — ₹21,000/night
* Honeymoon Cottage — ₹17,800/night

Each room includes a description, facilities, pricing, imagery, and a booking button.

### Amenities

Available resort amenities include:

* Swimming Pool
* Restaurant
* Spa
* Gym
* Free Parking
* Free Wi-Fi
* Event Hall
* Kids Play Area

The project also includes an animated infinity-pool highlight section.

### Gallery

The gallery displays resort, beach, room, villa, pool, and dining imagery. Users can open images in an interactive lightbox and navigate between images.

### Dining

The dining section features coastal cuisine, menu items with prices, and buffet timings for breakfast, lunch, and seafood BBQ dinner.

### Activities

Guests can explore activities such as:

* Beach Games
* Campfire
* Cycling
* Trekking
* Boating
* Indoor Games

### Booking

The booking section collects:

* Full Name
* Email
* Phone Number
* Number of Guests
* Check-in Date
* Check-out Date
* Room Type
* Special Requests

The form currently provides a frontend confirmation message after submission.

> **Note:** This is a frontend booking-request interface. The current implementation does not include a backend, database, payment gateway, or real reservation system. The JavaScript prevents the normal form submission and displays a confirmation message.

### FAQ

The FAQ section uses an interactive accordion to display answers about:

* Check-in and check-out
* Airport pickup
* Pet policy
* Cancellation policy

### Contact

The contact section includes:

* Resort address
* Phone number
* Email
* Social media UI
* Contact form
* Google Maps embed

The project currently uses Mahabalipuram, Tamil Nadu as the displayed resort location.
